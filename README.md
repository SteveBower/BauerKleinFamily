# BauerKleinFamily
Descendants of Johannes Bauer and Katharina Klein, immigrated from Germany to Ohio 1837

Just using this repo to host a static web page. The html was generated using a Gramps report, with data from an Ancestry.com tree. The report's html was then processed with a JS program to remove unwanted/redundant text, add introductory text, generate an index of names, etc. Custom CSS is used for enhanced formatting.
